# How to build
1) Make sure that "Valkyrien-Ship-Schematics" subproject pulled correctly
2) Build it (via terminal or whatever). It will publish dependency to local maven
3) (Optional) Pull [Markdown To Patchouli](https://github.com/SuperSpaceEye/markdown-to-patchouli) and build it, though you can also just comment out the plugin in common build script
4) Build VMod
